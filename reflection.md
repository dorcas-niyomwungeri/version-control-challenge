# Final Reflection

Through this project, I learned how version control helps track project changes over time. Git and GitHub make collaboration easier and help developers manage files safely. I learned how to create repositories, make commits, use branches, and merge pull requests.

The most difficult step was understanding how branches and pull requests work together. After practicing, I became more confident using Git commands.

Branches are useful because they allow developers to work on new features without changing the main project directly. Pull requests help review changes before merging them into the main branch.
