# Git and GitHub Notes

## What is Git?
Git is a version control system used to track changes in files and projects.

## What is GitHub?
GitHub is a platform used to host Git repositories online.

## Benefits of Version Control
- Tracks project history
- Helps collaboration
- Allows restoring previous versions

## what is a commit
commit is used to creat a message for the codes you pushed

## Common Git Commands
- git status
- git add .
- git commit -m "message"
- git push origin main
